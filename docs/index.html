Quick start

Using LIM Landscape Data

A Revit add-in for planting and floor environmental data — i-Tree benefit calculations, landscape data-sheet coefficients, and a rolled-up benefits dashboard — with each step as its own tool on the ribbon.

Getting the app onto your computer

Works with Revit 2025 and Revit 2026. Takes about five minutes, and you won't need an IT department or an admin password — it installs just for your own Windows account.

  1. 1

    Download the installer

    Open the download page and click the file named LIM-Landscape-Data-2025plus.zip. It's a large file, so it may take a few minutes to finish.

  2. 2

    Unzip the downloaded file

    Find the file — it's usually in your Downloads folder. Right-click it, choose Extract All…, then click Extract in the window that pops up. A new folder appears with the same name — open it.

  3. 3

    Open a text-command window inside that folder

    Hold down Shift on your keyboard, then right-click on an empty part of the folder (not on any file) and choose Open PowerShell window here (on some computers it says Open in Terminal). A blue or black window full of text opens — that's expected, not an error.

  4. 4

    Type one line, then press Enter

    Copy the line below, click inside that text window, right-click to paste it in, then press Enter:

    .\Deploy-BinaryPackage.ps1 -RevitVersion 2025

    Using Revit 2026 instead? Type this line instead:

    .\Deploy-BinaryPackage.ps1 -RevitVersion 2026

    If a blue screen appears saying "Windows protected your PC", click More info, then Run anyway. This is normal for a new tool that isn't from the Microsoft Store — it does not mean anything is wrong.

  5. 5

    Restart Revit

    If Revit is already open, close it completely and open it again. Look for a new tab along the top called LIM — everything below starts there.

📍 Everything lives under the LIM ribbon tab, in five panels, left to right — that order is the suggested workflow below.
Before anything else: open Settings and save your i-Tree API key, Airtable token, and data-sheet source once. Every other tool reads them from there — nothing to re-enter per project.
01

Project Setup

Get the model ready — parameters, species reference data, and site location.

Settings Save the i-Tree API key, Airtable token, and data-sheet source in one place.
Import Shared Parameter Load the shared-parameter file and bind the planting/i-Tree parameters to Project Information and Planting.
iTree Database Cacher Download the i-Tree species catalog (code, common and scientific name, type) and cache it locally for Tree Searcher.
Location Finder Pick a location on a map, search an address, or reuse the project's Site Location — publishes it to the i-Tree lat/long parameters.
KPI Schedules Generate Planting and Planting-Area schedules per Design Option, covering every KPI the Dashboard reports.
02

Data Processing

Get species and source data onto the model's elements.

Tree Searcher Search the cached species catalog and assign a species straight onto the selected Planting instances or types.
Excel Importer Import Excel or Airtable records, detect source units, preview changes, and write mapped Planting values.
03

Data Calculation

Turn the model's inputs into benefit results.

Tree Calculator Validate tree inputs, calculate i-Tree benefits, write the output parameters, and report anything missing.
Floor Calculator Match Floor instances to the landscape data sheet and calculate cost, carbon, air, water, and temperature benefits.
04

Diagnosis

Catch what changed or what's still incomplete.

Refresh and Audit Compare against the last pull, reapply changed data, and flag stale or incomplete planting elements.
Health Check Scan every Planting and Floor element for missing results, list what needs attention, and colour the active view red or green.
05

Reporting

See the results.

Benefits Dashboard Roll up i-Tree and data-sheet results into per-species and per-area subtotals and a project grand total — filter by Design Option or level, export as an image or Excel workbook.
